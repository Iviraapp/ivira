PWA Icon Requirements
=====================

Generate the following icons and place them in this directory:

1. icon-192.png   - 192x192px PNG, standard app icon
2. icon-512.png   - 512x512px PNG, standard app icon (used for splash screens)
3. icon-512-maskable.png - 512x512px PNG, maskable icon (safe zone: inner 80%)

Tips:
- Use a transparent background for standard icons
- Maskable icon should have a solid background color (#0A0A0F recommended)
  with the logo centered in the inner 80% safe area
- Test maskable icons at: https://maskable.app/editor
- You can generate all sizes from a single high-res SVG or PNG source
